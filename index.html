What is HTML?

HTML (HyperText Markup Language) is the standard markup language for creating web pages. It provides the structure and content of websites.

Getting Started

  1. Create a GitHub repository
  2. Navigate to Code → Codespaces → Create Codespace
  3. Create or open an index.html file
  4. Write your HTML code and save
  5. View your page in a web browser

1. Headings (h1 to h6)

Headings are used to create titles and section headers. They range from <h1> (largest) to <h6> (smallest).

<h1>This is a heading 1</h1>
<h2>This is a heading 2</h2>
<h3>This is a heading 3</h3>

2. Paragraphs (<p>)

The <p> tag defines a paragraph of text.

<p>This is a paragraph of text.</p>

3. Text Formatting

Strong/Bold Text

Use <strong> to make text bold and give it semantic importance.

<p>This is <strong>bold text</strong></p>

This is bold text

Strikethrough Text

Use <s> to strike through text.

<s>This text is struck through</s>
This text is struck through

Line Breaks

Use <br> to create a line break.

<p>Line 1<br>Line 2</p>

Line 1
Line 2

4. Definition and Abbreviation Tags

Definition Tag (<dfn>)

The <dfn> tag marks the definition of a term.

<p><dfn>HTML</dfn> is a markup language.</p>

HTML is a markup language.

Abbreviation Tag (<abbr>)

The <abbr> tag marks an abbreviated term with the full form in the title attribute.

<p><abbr title="HyperText Markup Language">HTML</abbr></p>

HTML (hover over to see full form)

5. Styling with Colors and Fonts

Text Color

Use inline CSS with the style attribute to change text color.

<p style="color: red;">This text is red</p>

This text is red

Colored Divs

Use <div> to create containers with custom styling.

<div style="color: blue; background-color: lightblue; padding: 10px;">
  Blue colored content
</div>
Blue colored content

Font Families

Use the style attribute to change fonts.

<p style="font-family: Arial, sans-serif;">Text in Arial</p>

Text in Arial

Text in Georgia

6. Images

Use <img> to embed images on your page.

<img src="image.jpg" alt="Description" style="width: 200px; height: auto;">

Attributes:

  • src - Path to the image file
  • alt - Alternative text if image doesn't load
  • style - CSS styling (width, height, etc.)

7. Lists

Unordered Lists (<ul>)

<ul>
  <li>Item 1</li>
  <li>Item 2</li>
</ul>

Ordered Lists (<ol>)

<ol>
  <li>First item</li>
  <li>Second item</li>
</ol>

8. Document Structure

Every HTML document should have this basic structure:

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <title>Page Title</title>
</head>
<body>
  <!-- Your content here -->
</body>
</html>
